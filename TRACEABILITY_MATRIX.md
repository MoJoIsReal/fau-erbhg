# Traceability matrix

Flows and IDs come from `.review/02-architecture.md`. This architecture has no service layer: each handler validates input, runs SQL and maps the response itself (AGENTS.md "One backend"). The **Service** column therefore names the shared helper a flow relies on, if any.

**Status legend:**
- **PASS:** every hop was checked.
- **PARTIAL:** the flow works for normal use, but one hop has a confirmed defect.
- **FAIL:** the flow produces a wrong outcome under realistic conditions. The broken hop is named.

**Totals: 10 PASS · 5 PARTIAL · 1 FAIL · 0 UNVERIFIED · 0 DEAD · 0 ORPHANED.** One ORPHANED route alias (`staff-users`) is listed under TRACE-006.
